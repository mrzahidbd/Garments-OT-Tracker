# Garments OT Tracker

সহজ বাংলা হাজিরা, ওভারটাইম ও সম্ভাব্য বেতন হিসাবের ওয়েব অ্যাপ।

## ফিচার
- দৈনিক OT, নাইট ডিউটি, হলিডে, টিফিন ও অনুপস্থিতি এন্ট্রি
- মাসভিত্তিক ক্যালেন্ডার, হিসাব ও বেতন সারাংশ
- WhatsApp-এ হিসাব শেয়ার এবং JSON ব্যাকআপ/রিস্টোর
- Excel-এ খোলার উপযোগী মাসিক CSV রিপোর্ট
- ঐচ্ছিক PIN লক (PBKDF2 hash; ৫ মিনিট নিষ্ক্রিয় থাকলে বা অ্যাপ লুকালে লক)
- নোট নিরাপদে HTML escape করা এবং ব্যাকআপ ইমপোর্টে ডাটা যাচাই
- ঐচ্ছিক অনুদান: বাংলাদেশের MFS নম্বর 01402047272 (bKash, Nagad, Rocket, Upay)

## চালানোর নিয়ম
1. `index.html` ফাইলটি ব্রাউজারে খুলুন অথবা GitHub Pages চালু করুন।
2. Settings থেকে নিজের নাম, বেতন ও OT রেট সেট করুন।
3. প্রতিদিনের হাজিরা ও OT যোগ করুন।
4. নিয়মিত JSON ব্যাকআপ ডাউনলোড করে নিরাপদ জায়গায় রাখুন।

## GitHub Pages
Repository Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
প্রকাশিত হলে GitHub Pages URL-এ অ্যাপ চালু হবে।

## গোপনীয়তা ও সীমাবদ্ধতা
- হিসাবের ডাটা এই ব্রাউজারের localStorage-এ থাকে; অন্য ডিভাইসে স্বয়ংক্রিয়ভাবে sync হয় না।
- PIN লক casual access কমায়, কিন্তু localStorage ডাটা encrypt করে না। এটি server-side account/security system নয়।
- অনুদান সম্পূর্ণ ঐচ্ছিক। অ্যাপ কোনো পেমেন্ট গ্রহণ, যাচাই বা রসিদ তৈরি করে না।
- অ্যাপটি বেতন/OT-এর আনুমানিক হিসাব দেয়; প্রতিষ্ঠানের অনুমোদিত payroll statement-এর বিকল্প নয়।
